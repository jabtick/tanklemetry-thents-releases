# TANKlemetry releases

Installers and update files for TANKlemetry. The app checks this repository
for new versions and downloads them by itself.

- Installers: see **Releases**.
- `app/latest.json`: the newest version (signed; the app checks the signature).
- `tracks/track-data.json`: the venue list and track edges (signed).

No source code lives here. TANKlemetry is proprietary software: all rights
reserved. Use is governed by the licence agreement shown by the installer.
